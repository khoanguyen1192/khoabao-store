Support

How can we help?

PlatePact: 3D Print Planner is a local planning tool. Include your device model, iOS/iPadOS version, and a short non-sensitive description when reporting an issue.

Quick help

I cannot reach a decision

Check that at least one FDM printer is configured and that the requested date is in the future. Review the plate count, per-plate duration, and rework buffer. PlatePact: 3D Print Planner only schedules staffed starts from 08:00–20:00 in this version.

The result is conditional or do not promise

Read the visible schedule slack and affected-commitment explanation. Try a later requested date, more capacity, a different priority, or a changed buffer. The result is an estimate—not a guarantee.

G-code import did not work

File assistance is experimental. Only supported text G-code metadata may be offered, and you must confirm extracted duration. Enter the slicer duration manually whenever a file is unsupported, ambiguous, or unreadable.

How do I restore Pro?

Open Shop → Restore purchases while signed in to the same App Store account used to buy PlatePact: 3D Print Planner Pro. If restoration still fails, confirm your connection and contact support with non-sensitive device details.

How do I erase local data?

Open Shop → Erase all PlatePact: 3D Print Planner data. This removes local commitments and setup from the device. Purchases are not erased and can be restored separately.

Contact
